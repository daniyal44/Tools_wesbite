## FAQ

**How do you align columns in Markdown tables?**

Markdown uses colons in the header divider row: :--- for left alignment, :---: for center alignment, and ---: for right alignment.

**Can I export the table to HTML format?**

Yes! Toggle the HTML Tab to copy semantic <table>, <thead>, and <tbody> markup directly into your CMS or web page.
