## FAQ

**Does it replace all occurrences at once?**

Yes. Every match is replaced in one pass and the live counter shows exactly how many replacements were made.

**Can I use regular expressions?**

Yes. Enable Regex mode to use full JavaScript regular-expression patterns, including capture groups like $1 in the replacement field. Invalid patterns are flagged instead of breaking.

**Is my text sent to a server?**

No. All find-and-replace processing happens entirely in your browser; nothing is uploaded.
