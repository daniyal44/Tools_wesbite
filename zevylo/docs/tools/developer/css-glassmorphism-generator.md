## FAQ

**What CSS property creates the frosted glass effect?**

The primary property is backdrop-filter: blur(Xpx), paired with a semi-transparent background color (e.g., rgba(255, 255, 255, 0.2)) and a subtle border.

**Is backdrop-filter supported in all modern browsers?**

Yes! It is supported in modern Chrome, Edge, Safari (with -webkit-backdrop-filter prefix), and Firefox.
