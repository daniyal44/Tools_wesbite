## What it does

Turn disorganized, single-line SQL queries into clean, beautifully indented, readable SQL code. Automatically standardizes keywords (SELECT, FROM, WHERE, JOIN, GROUP BY, ORDER BY, INSERT, UPDATE, DELETE) to uppercase and aligns clauses.

## FAQ

**Which SQL dialects are supported by this formatter?**

Standard ANSI SQL syntax is supported, making it fully compatible with MySQL, PostgreSQL, SQLite, Microsoft SQL Server, and Oracle queries.

**Is my SQL database schema or query data sent to any server?**

No. Formatting runs 100% locally inside your browser. No query data or sensitive schema names are ever transmitted.
