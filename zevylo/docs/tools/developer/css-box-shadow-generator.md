## FAQ

**How do you create soft modern box shadows in CSS?**

Use a larger blur radius (e.g. 25px - 50px) combined with low shadow opacity (e.g. 0.05 - 0.15) and a slight negative spread to create smooth, realistic depth.

**What does the inset property do in box-shadow?**

The inset keyword reverses the shadow direction, drawing it inside the border of the element rather than outside.
