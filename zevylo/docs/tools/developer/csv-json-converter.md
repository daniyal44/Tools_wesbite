## What it does

A two-way CSV ⇄ JSON converter that parses properly per RFC 4180 — quoted fields, escaped quotes, and commas or line breaks inside values are all handled correctly. Choose your delimiter (comma, semicolon, tab, or pipe), toggle a header row, then copy or download the result. Everything runs locally in your browser; your data is never uploaded.

## FAQ

**Does it handle commas inside quoted CSV fields?**

Yes. The parser follows RFC 4180, so quoted fields containing commas, line breaks, or escaped double-quotes ("") are parsed correctly.

**Can I convert JSON back to CSV?**

Yes. Switch to JSON → CSV mode and paste an array of objects (or arrays). Column headers are derived from the object keys automatically.

**Is my data uploaded anywhere?**

No. All parsing and conversion happens entirely in your browser — nothing is sent to any server.
