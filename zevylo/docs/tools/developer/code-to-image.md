## FAQ

**Is this an alternative to Ray.so and Carbon?**

Yes! Zevylo Code to Image provides stunning code card exports with customizable padding, multiple IDE themes, window dots, and vibrant gradients without watermarks.

**Can I copy the generated code card directly to clipboard?**

Yes, you can click "Copy Image" to instantly paste the PNG into Slack, Discord, Twitter, or Google Docs, or download the high-DPI image.

**Is my source code uploaded to any server?**

No. Everything is rendered 100% locally in your browser using the HTML5 Canvas API. Your code never leaves your computer.
