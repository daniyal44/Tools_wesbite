## FAQ

**What do the numbers in chmod 755 mean?**

The first digit (7) is Owner permissions (r+w+x = 4+2+1). The second digit (5) is Group permissions (r+x = 4+1). The third digit (5) is Public/Others permissions (r+x = 4+1).

**What are the most common Linux file permissions?**

Standard files are usually chmod 644 (owner can read/write, everyone else read-only). Web scripts and directories are usually chmod 755 (owner full access, others can read & execute).
