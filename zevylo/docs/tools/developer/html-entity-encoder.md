## FAQ

**Why do characters need to be HTML entity encoded?**

Characters like <, >, &, and " have special syntactic meaning in HTML. Encoding them prevents them from being parsed as HTML tags, mitigating cross-site scripting (XSS) risks.

**What is the difference between named and numeric entities?**

Named entities use recognizable codes like &amp; while numeric entities use character codes like &#38; (decimal) or &#x26; (hexadecimal).
