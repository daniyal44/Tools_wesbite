## FAQ

**Does this handle deeply nested JSON objects?**

Yes! The generator recursively extracts child objects into clean, reusable separate TypeScript interfaces.

**Can I choose between interfaces and type aliases?**

Yes, you can toggle between "export interface" and "export type" syntax with a single checkbox.

**Is my confidential JSON data uploaded to a server?**

No. All parsing and TypeScript code synthesis happens entirely in your local browser.
