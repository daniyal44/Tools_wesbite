**Does this converter support nested structures and arrays?**

Yes! Nested objects, multidimensional arrays, booleans, null values, and strings are fully preserved in both directions.

**Is my data secure?**

All parsing occurs locally in your browser. No confidential tokens, environment variables, or config payloads are transmitted to any server.
