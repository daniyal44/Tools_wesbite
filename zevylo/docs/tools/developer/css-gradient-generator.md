## FAQ

**How do you apply a CSS gradient to a webpage background?**

Copy the generated CSS snippet (e.g. background: linear-gradient(135deg, #4f46e5, #06b6d4);) and paste it into your CSS stylesheet or Tailwind arbitrary value.

**What is the difference between linear and radial gradients?**

Linear gradients transition colors along a straight directional line (defined by angles), whereas radial gradients radiate outward from a central point.
