## What it does

Clean and sanitize messy, cluttered web URLs. Instantly strips tracking queries and spy parameters including utm_source, utm_medium, utm_campaign, utm_content, utm_term, fbclid, gclid, mc_eid, igshid, msclkid, ref, and affiliate tokens. Supports batch cleaning of multiple links simultaneously, canonical URL normalization, and privacy protection.

## FAQ

**Which tracking parameters are stripped?**

All common marketing trackers: utm_*, fbclid, gclid, msclkid, dclid, mc_eid, igshid, ref, source, and affiliate tracking IDs.

**Does this modify important functional query parameters?**

No! It preserves essential parameters like search queries (?q=...), page pagination (?p=2), or video timestamps (?t=45s).
