## What it does

Generate valid, standard-compliant XML sitemaps ready for submission to Google Search Console and Bing Webmaster Tools. Add individual or batch URLs, configure priority levels (0.1 to 1.0), set change frequencies (always, hourly, daily, weekly, monthly, yearly, never), and include ISO 8601 last modified timestamps. Includes live syntax validation, one-click copy, and instant sitemap.xml file download.

## FAQ

**Where should I upload the generated sitemap.xml?**

Place the generated sitemap.xml file in the root directory of your website (e.g., https://example.com/sitemap.xml) and submit the URL in Google Search Console.

**What is the maximum number of URLs allowed in a single sitemap?**

According to the official sitemaps.org protocol, a single sitemap file can contain up to 50,000 URLs and must not exceed 50MB uncompressed.
