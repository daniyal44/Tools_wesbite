## FAQ

**Does this converter preserve HTML tables and lists?**

Yes! HTML <table>, <thead>, <tbody>, <tr>, and <td> elements are automatically converted into clean GitHub-flavored Markdown table pipes (| Col 1 | Col 2 |).

**Is my HTML uploaded to any external server?**

No. The parsing and transformation logic executes 100% locally inside your web browser with complete client-side privacy.
