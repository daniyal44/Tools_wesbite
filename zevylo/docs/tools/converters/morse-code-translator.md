## FAQ

**How are dots and dashes represented in timing?**

Standard International Morse code timing: a dot (dit) is 1 time unit, a dash (dah) is 3 units, silence between parts of the same letter is 1 unit, space between letters is 3 units, and space between words is 7 units.

**Can this tool decode raw Morse code back into English?**

Yes! Simply paste dots and dashes (separated by spaces between letters and slashes "/" between words) to instantly decode back to text.
