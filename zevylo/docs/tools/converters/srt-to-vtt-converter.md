## FAQ

**What is the key difference between SRT and VTT subtitles?**

WebVTT files must start with the header line "WEBVTT" and use periods for milliseconds (00:00:01.000), whereas SRT files use commas (00:00:01,000) and require sequential number cues.

**Can I upload an .srt file directly?**

Yes! Drag and drop or choose any .srt or .vtt file to convert and download the converted subtitle file in one click.
