## FAQ

**How does text to binary conversion work?**

Each character has an ASCII/Unicode code number (e.g. "A" is 65). This number is converted to base-2 binary format (65 in binary is 01000001).

**Can this tool decode binary strings with or without spaces?**

Yes! Zevylo automatically detects and decodes both space-separated binary ("01001000 01101001") and continuous binary streams.
