## FAQ

**Is my secret key transmitted across the internet?**

Never. The HMAC computation is executed locally inside your web browser using window.crypto.subtle. Zero data is sent to external servers.

**Which HMAC algorithms are supported?**

Standard cryptographic algorithms: HMAC-SHA-256, HMAC-SHA-384, and HMAC-SHA-512 with Hex and Base64 output options.
