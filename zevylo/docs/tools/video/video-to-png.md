## FAQ

**Why extract frames as PNG instead of JPG?**

PNG uses lossless compression, meaning every pixel is preserved with 100% precision and zero compression artifacts. It is ideal for graphic design, video editing assets, text overlays, and high-detail captures.

**Can I copy extracted PNG frames directly to my clipboard?**

Yes! Every extracted PNG frame features an instant 1-click "Copy" button that places the PNG directly onto your system clipboard for immediate pasting into Figma, Photoshop, Discord, or Slack.

**Is there a file size limit?**
