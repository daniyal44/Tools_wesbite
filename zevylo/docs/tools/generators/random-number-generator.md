## What it does

Generate truly random numbers within any range you choose. Pick a minimum and maximum, how many numbers you need (up to 10,000), and the number of decimal places, then optionally require all values to be unique or sort them ascending. Perfect for raffles, sampling, test data, and games. Numbers are produced with your browser’s cryptographically secure generator using bias-free rejection sampling.

## FAQ

**Is this random number generator secure?**

Yes. It uses crypto.getRandomValues (your browser’s cryptographically secure RNG) with rejection sampling, so the numbers are unbiased and not predictable like Math.random.

**Can I generate unique numbers with no repeats?**

Yes. Enable "No duplicates" to guarantee every generated integer is unique — ideal for raffles and lotteries. The count must fit within the chosen range.

**Can it generate decimals?**

Yes. Set "Decimal places" to 1 or more to generate random decimal numbers instead of whole integers.
