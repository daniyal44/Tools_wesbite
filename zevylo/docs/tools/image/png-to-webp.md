## FAQ

**Does WebP keep transparency?**

Yes. WebP supports an alpha channel, so transparent PNG areas stay transparent after conversion.

**How much smaller is WebP?**

WebP is typically 25–35% smaller than PNG at comparable quality, which speeds up page loads.
