## What it does

Resize any image precisely by width/height in pixels or by percentage, with an optional aspect-ratio lock so proportions stay correct. Scale down for the web or up for printing, choose the output format (PNG, JPG, WebP) and quality, then download. Everything runs locally in your browser.

## FAQ

**Can I enlarge a small image?**

Yes. Set a larger size or a percentage above 100%. Note that upscaling cannot add detail that was not in the original.

**Will the aspect ratio stay correct?**

Keep the lock enabled and changing width auto-adjusts height (and vice versa) to preserve proportions.
