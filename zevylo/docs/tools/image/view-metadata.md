## FAQ

**What metadata can I view?**

You can inspect file size, exact pixel dimensions, aspect ratio, MIME type, camera details, color profile, and binary magic bytes.

**Are my files sent to any server?**

No. The file is analyzed strictly within your local browser memory.

**Can I copy the metadata summary?**

Yes! A single click copies a structured JSON or formatted text report to your clipboard.
