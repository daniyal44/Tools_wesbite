## FAQ

**Should I use a square image?**

Yes. Icons are square, so a square source avoids letterboxing. Non-square images are centered and padded.

**Does the icon keep transparency?**

JPG has no transparency, so the icon background will be solid. Use PNG to ICO if you need a transparent icon.
