## FAQ

**Does transparency survive the conversion?**

Yes. PNG supports alpha transparency, so transparent WebP areas remain transparent.

**Why convert WebP to PNG?**

Some older software and platforms do not accept WebP, so PNG is a safe, lossless fallback.
