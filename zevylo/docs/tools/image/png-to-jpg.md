## FAQ

**Why did my transparent background turn white?**

JPG does not support transparency, so transparent pixels are filled with white when converting from PNG.

**Can I convert multiple PNG files at once?**

Yes. Drop or select several PNG files and each one is converted; use “Download all” to save them in one click.
