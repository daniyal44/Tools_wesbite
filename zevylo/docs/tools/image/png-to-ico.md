## FAQ

**What sizes should a favicon include?**

16×16 and 32×32 cover most browsers; adding 48 and 256 improves Windows and high-DPI displays.

**Is this a real .ico file?**

Yes. It produces a standards-compliant ICO containing PNG-compressed entries, supported by all modern systems.
