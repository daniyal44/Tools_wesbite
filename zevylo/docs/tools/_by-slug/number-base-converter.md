## What it does

Instantly convert integers between binary (base 2), octal (base 8), decimal (base 10), hexadecimal (base 16), and any custom base from 2 to 36. Handles arbitrarily large whole numbers with exact BigInt precision, accepts 0x / 0b / 0o prefixes, and lets you copy any result with one click — all processed privately in your browser.

## FAQ

**How do I convert decimal to binary?**

Enter your decimal number, set the input base to 10, and read the Binary (base 2) result card — you can copy it with one click.

**Does it handle very large numbers?**

Yes. Conversions use JavaScript BigInt, so even numbers far beyond 64 bits convert exactly without rounding errors.

**Can I use 0x or 0b prefixes?**

Yes. When the input base matches, prefixes like 0x (hex), 0b (binary), and 0o (octal) are accepted and ignored during parsing.
