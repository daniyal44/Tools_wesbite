## FAQ

**What is a Data URI?**

A Data URI allows image binary data to be encoded directly into text (Base64) and embedded inside HTML or CSS files, eliminating separate HTTP image requests.

**When should I use Data URIs?**

Data URIs are ideal for small icons, logos, email signatures, single-file HTML landing pages, and reducing server network requests.

**Are my images secure?**

Yes! The FileReader API converts your image strictly inside your local browser memory. No data is transmitted across the internet.
