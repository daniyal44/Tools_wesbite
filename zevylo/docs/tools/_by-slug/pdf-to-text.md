## What it does

Fast, secure client-side PDF text extractor. Pull text, paragraphs, and content out of PDF files without uploading them to any cloud or third-party server. Includes live text search, word and character counters, clean text formatting, one-click clipboard copy, and instant .txt file export. Direct private Stirling-PDF and TinyWow alternative.
