## FAQ

**What is CIDR notation?**

Classless Inter-Domain Routing (CIDR) uses a slash followed by a number (like /24) to represent the number of consecutive leading bits in the subnet mask.

**How many usable hosts are in a /24 subnet?**

A /24 subnet contains 256 total IP addresses, with 254 usable hosts (subtracting the network and broadcast addresses).
