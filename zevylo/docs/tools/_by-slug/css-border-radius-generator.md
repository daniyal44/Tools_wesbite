## FAQ

**How does 8-point CSS border-radius work?**

Standard CSS border-radius accepts horizontal and vertical values separated by a slash (e.g., border-radius: 30% 70% 70% 30% / 30% 30% 70% 70%), enabling asymmetrical, organic curves and blobs.

**Is 8-point border-radius supported by all modern browsers?**

Yes! The slash syntax is fully supported by Chrome, Safari, Firefox, Edge, and mobile browsers without prefixes.
