## FAQ

**What does CSS clamp() do for typography?**

clamp(min, preferred, max) lets a font size grow smoothly between a minimum and maximum as the viewport changes, giving responsive type without multiple media-query breakpoints.

**How is the preferred value calculated?**

It computes the straight line between your two viewport/size pairs, expressed as a rem offset plus a vw slope, then clamps it between your min and max sizes in rem.

**Why rem and vw?**

rem keeps the min/max tied to the root font size (good for accessibility and zoom), while vw drives the smooth scaling with viewport width.
