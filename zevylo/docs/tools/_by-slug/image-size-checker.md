## FAQ

**How are megapixels calculated?**

Megapixels = (width × height) ÷ 1,000,000. A 4000×3000 image is 12 MP.

**What does print size mean?**

It is the physical size the image would print at a given DPI, e.g. 3000px ÷ 300 DPI = 10 inches.
