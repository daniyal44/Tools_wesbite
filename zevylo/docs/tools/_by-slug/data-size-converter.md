## FAQ

**What is the difference between decimal (SI) and binary (IEC)?**

Decimal (SI) uses base-10 where 1 KB = 1000 Bytes. Binary (IEC) uses base-2 where 1 KiB = 1024 Bytes. Storage manufacturers often use decimal, while operating systems often use binary.
