## FAQ

**What is the formula for calculating aspect ratio dimensions?**

If ratio is W:H: New Height = (New Width × H) / W, and New Width = (New Height × W) / H.

**What aspect ratio is used for Instagram Reels, TikTok, and YouTube Shorts?**

Vertical mobile videos use a 9:16 aspect ratio (standard resolution is 1080 × 1920 pixels).
