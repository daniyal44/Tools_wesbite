## FAQ

**Why convert a GIF to MP4?**

MP4 videos use modern H.264/WebM compression, making them up to 10x smaller in file size while supporting smoother 60 FPS playback on web pages and social media.

**Are my GIF files uploaded to any server?**

No. The conversion is rendered directly inside your browser using HTML5 Canvas and the MediaStream Recording API.
