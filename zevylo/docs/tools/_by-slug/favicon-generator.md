## FAQ

**What sizes should a modern website favicon package include?**

The standard minimum package includes 16x16 (browser tabs), 32x32 (taskbar/shortcuts), 48x48 (desktop high-DPI), and 180x180 (iOS Apple Touch icon).

**How do I add the generated favicon to my HTML website?**

Place the exported icon files in your root public folder and paste the generated <link rel="icon"> tags into your HTML <head> section.
