## FAQ

**What is the difference between encodeURI and encodeURIComponent?**

encodeURI preserves special URL characters like "/", "?", and "&" for full web addresses, while encodeURIComponent escapes all characters to safely embed values inside query strings.

**Can this tool parse query strings into JSON?**

Yes! The built-in query parameter inspector breaks down every URL parameter into key-value pairs and allows one-click export to JSON.
