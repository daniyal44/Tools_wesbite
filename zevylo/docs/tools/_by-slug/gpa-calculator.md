## FAQ

**How is GPA calculated on a 4.0 scale?**

Each letter grade corresponds to a numeric point value (A = 4.0, B = 3.0, C = 2.0, D = 1.0, F = 0.0). Multiply points by course credits to get Quality Points. GPA = Total Quality Points / Total Credits.

**Does this calculator support +/- grades?**

Yes! Zevylo supports the standard university scale including A (4.0), A- (3.7), B+ (3.3), B (3.0), B- (2.7), C+ (2.3), C (2.0), D (1.0), and F (0.0).
