## FAQ

**How does this tool extract colors from images?**

It samples pixels from the uploaded image onto an HTML5 Canvas, quantizes RGB values into color clusters, and identifies the most prominent color families by density.

**Can I export the extracted palette into my code?**

Yes! You can export with one click to CSS Custom Properties (:root variables), Tailwind CSS configuration snippet, or structured JSON.
