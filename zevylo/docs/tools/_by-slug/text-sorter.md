## FAQ

**Can I sort a list alphabetically?**

Yes. Choose A→Z or Z→A. Enable "Case-insensitive" so capitalization does not affect the order.

**Does it sort numbers correctly?**

Yes. The Numeric modes read the first number in each line and sort by value, so 2 comes before 10 (unlike plain text sorting).

**Can I randomize the order?**

Yes. Pick Shuffle to randomly reorder the lines, and press Re-shuffle for a new random arrangement.
