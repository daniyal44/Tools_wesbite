## FAQ

**How does image-to-ASCII art generation work?**

The image is resized onto an HTML5 Canvas and each pixel’s luminance (brightness) is mapped to an ASCII character based on character optical density (e.g., @ for dark pixels, . for light pixels).

**Can I copy the ASCII output directly into code or markdown?**

Yes! The output is formatted in clean monospace text, ready to paste into Markdown code fences (```) or program source files.
