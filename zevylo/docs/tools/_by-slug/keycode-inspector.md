## FAQ

**What is the modern standard replacement for event.keyCode?**

The W3C recommends using event.key (the printed value, like "Enter" or "a") and event.code (the physical key position, like "KeyA") instead of the deprecated event.keyCode.

**Does this inspector detect modifier keys?**

Yes! It tracks Shift, Control, Alt/Option, and Meta/Command (Windows/Mac) state flags on every key press.
