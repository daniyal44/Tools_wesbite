## FAQ

**Is this metronome sample-accurate?**

Yes! It utilizes the browser’s Web Audio API high-resolution hardware clock, ensuring completely drift-free timing unlike standard JavaScript setTimeout.

**What time signatures are supported?**

Standard time signatures including 2/4, 3/4, 4/4, 5/4, 6/8, and 7/8 with accented primary downbeats are supported.
