## What it does

Direct alternative to Vectary and ViewSTL. Pure client-side 3D viewer supporting both Binary and ASCII STL file formats. Inspect 3D models with interactive mouse drag rotation, zoom, wireframe and solid lighting modes, bounding box dimension measurements (X, Y, Z in mm), triangle / facet counters, and sample models (Cube, Prism, Tetrahedron). Completely private: files are never uploaded to any remote server.

## FAQ

**Does this viewer support both Binary and ASCII STL files?**

Yes! The custom parser auto-detects whether the file header is Binary STL (standard 80-byte header + triangle count) or ASCII STL (plain-text facet coordinates).

**Are my CAD files uploaded to any server?**

Never. All 3D rendering and mesh calculations happen 100% locally in your browser memory using HTML5 Canvas.
