## FAQ

**What can I count down to?**

Any future date and time — holidays, product launches, exams, birthdays, deadlines, or the New Year. Use the presets or set a custom date and time.

**Does it keep running if I leave the page open?**

Yes. The countdown updates every second while the tab is open and recalculates from the real clock, so it stays accurate.

**What happens when the countdown reaches zero?**

It switches to show how much time has elapsed since the event, so you can see both before and after.
